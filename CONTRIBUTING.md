# Contributing to SDL3 DrawReady

¡Gracias por tu interés en contribuir! Toda ayuda es bienvenida, desde la corrección de un bug hasta la optimización de las estructuras de datos.

## Flujo de Trabajo (Workflow)
1. Haz un **Fork** del repositorio.
2. Crea una nueva rama para tu característica o corrección: `git checkout -b feature/MiNuevaClase` o `fix/BugEnRenderizado`.
3. Haz tus cambios asegurándote de mantener el código limpio y comentado donde sea necesario.
4. Haz **Commit** de tus cambios usando mensajes claros y descriptivos.
5. Haz **Push** a tu rama: `git push origin feature/MiNuevaClase`.
6. Abre un **Merge Request / Pull Request** hacia la rama `main`.

## Reporte de Bugs
Por favor, utiliza las plantillas de *Issues* proporcionadas en el repositorio para reportar bugs. Asegúrate de incluir logs del compilador y detalles de la arquitectura (x64/x86).
